# C01 — Kaarisillan kokonaisvaltainen liiketoiminnan kehitys

**Asiakas:** Kaarisilta Teollisuuspalvelut Oy. **Toimittaja:** Tekoväläys Oy Ab.

> Tämä on kokonainen synteettinen projektisuunnitelma ja mallituotosten paketti. Tilannepäivä on 22.9.2026, ja projekti alkaa vasta 5.10.2026. Tutkimushavainnot ovat keksittyjä suunnitteluoletuksia. Pilotin tuloksia tai päätöksiä ei esitetä toteutuneina.

Haastattelukansio sisältää erillisen, käsikirjoitetun tutkimusskenaarion. Sen luominen ei muuta projektin tilaa toteutuneeksi tutkimukseksi eikä sulje avoimia päätöksiä. [Koonti ja johtopäätökset](12_haastattelut/01_koonti_ja_johtopaatokset.md) kokoaa havainnot jäljitettävin haastatteluviittein.

Lue ensin nykytila, strategia ja liiketoimintasuunnitelma. Operatiiviseen projektityöhön tarvitaan lisäksi aikataulu, budjetti ja hyväksymiskriteerit. Kaikki euromäärät ovat alv 0 %.
